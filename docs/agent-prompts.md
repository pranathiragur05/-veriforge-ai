# Prompt Design

## Verifier principles
- Never trust the generator's conclusion.
- Verify important claims independently.
- Require evidence for factual assertions.
- Recalculate important numerical results independently.
- Execute code where safe and appropriate.
- Surface contradictions rather than silently choosing a source.
- Abstain when reliable evidence is insufficient.

## Finalizer
Accept only when blocking verification checks pass. Explain rejection reasons and confidence.
